# 多光标页面搭建

`original.html` 是用户直接提供的文件，保持原内容，生成器发布可下载副本。`source.html` 为此前完成Logo替换、性能优化及选框对齐修正的独立HTML，用作当前界面和内嵌资源的输入。

原生交互核心维护于上级 `multi-cursor-builder.mjs`，不在iframe内执行。改动逻辑应修改该核心；样式及资源修改source.html，再通过现有motion:build生成分发文件。字体保留原OFL版权声明，单独注册准确的字重和斜体，按文档引用计数清理。

文件来自用户会话，未提供可核实的外部原作地址或图片上游许可。页面中的姓名、项目和统计为该HTML演示内容，不作为真实业务数据发布声明。
