# 中英文界面

默认中文，导航按钮 **EN / 中** 切换语言。语言偏好存储在浏览器 `canvasui:locale`，刷新、站内导航及同源标签页保持同步。禁用存储时仍可在当前页面切换。

覆盖主页、全局导航和搜索、组件列表、四篇指南、35 个组件介绍及参数说明、演练场、订阅、隐私和 Celebrate 界面。技术名称、品牌、代码、安装命令、API 属性名和数值保持原文。面向 AI 的技术提示词保留英文。

`src/lib/i18n/` 集中保存词典；`LanguageProvider` 提供语言状态，`T` 翻译展示文案且不增加 DOM 容器。未知文案保留原文。
