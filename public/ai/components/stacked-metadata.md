# Stacked Metadata Tags / 标签叠放展开

Overlapping priority, date and assignee tags leave room for task titles, then spread to the left when a row is hovered or focused.

优先级、日期和负责人标签相互叠放，为任务标题留出空间；悬停或聚焦时向左展开。
