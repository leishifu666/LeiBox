# Glyph Rain / 字符雨

Falling glyph streams that light up your live HTML, with drop heads that surge where your cursor cuts through.

下落的字符流照亮网页，指针扫过时会激起字符涌动。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/glyph-rain) · [Canvas UI source](https://canvasui.dev/docs/components/glyph-rain)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
