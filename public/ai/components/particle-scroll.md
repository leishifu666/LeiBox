# Particle Scroll / 粒子滚动

Dissolves your live HTML below a chosen line into fine sand particles that reassemble on scroll.

把指定位置下方的网页内容化为细沙，滚动时粒子逐渐拼回原状。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/particle-scroll) · [Canvas UI source](https://canvasui.dev/docs/components/particle-scroll)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
