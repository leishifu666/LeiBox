# Asciify / 字符透镜

A soft lens that follows your cursor and redraws the live HTML beneath it as ascii characters.

透镜随指针移动，将下方的网页内容重绘为 ASCII 字符。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/asciify) · [Canvas UI source](https://canvasui.dev/docs/components/asciify)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
