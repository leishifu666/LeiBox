# Liquid Object / 流体物体

Drags any 3D model, SVG, or image through invisible liquid that swirls under the cursor and splits the light into color.

将三维模型、SVG 或图片浸入隐形液体。指针带起的水流拖动形体，并将光线分解为颜色。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/liquid-object) · [Canvas UI source](https://canvasui.dev/docs/components/liquid-object)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
