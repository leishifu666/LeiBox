# Particle Object / 粒子物体

Rebuilds any 3D model, SVG, or image as particles that scatter around the cursor and spring back into shape.

将三维模型、SVG 或图片重建为粒子。粒子随指针散开，再弹回原形。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/particle-object) · [Canvas UI source](https://canvasui.dev/docs/components/particle-object)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
