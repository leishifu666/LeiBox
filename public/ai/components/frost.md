# Frost / 冰霜

A frozen pane of ice over your live HTML that melts under the cursor and refreezes.

在网页上覆盖冰层。指针经过时冰面融化，移开后重新凝结。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/frost) · [Canvas UI source](https://canvasui.dev/docs/components/frost)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
