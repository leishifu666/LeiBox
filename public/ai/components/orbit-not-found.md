# Orbit 404 Page / 组件环游 404

A 404 page that turns component previews into an orbit. Hover or focus a card to pause it, and open the component from the ring.

把组件预览排成环形轨道的 404 页面。悬停或聚焦卡片时暂停转动，选中卡片即可打开对应组件。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/orbit-not-found) · [LeiBox source](https://github.com/leishifu666/LeiBox/tree/main/src/components/not-found-experiments)

Use the GitHub source and the LeiBox documentation to integrate this React / Next.js example.

通过 GitHub 查看 React / Next.js 源码，结合 LeiBox 文档接入。
