# Window Shade Theme Toggle / 舷窗遮光板主题切换

Drag an airplane window shade to dim the cabin, hide drifting clouds and switch the surrounding profile between light and dark themes.

拖动舷窗遮光板，机舱随之变暗、云层被遮住，个人介绍同步切换明暗主题。
