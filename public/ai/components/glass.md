# Glass / 玻璃透镜

A cursor-following glass lens that refracts your live HTML and zooms in on targets like a crystal ball.

玻璃透镜跟随指针，折射并放大下方的网页内容。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/glass) · [Canvas UI source](https://canvasui.dev/docs/components/glass)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
