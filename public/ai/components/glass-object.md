# Glass Object / 玻璃物体

Turns any 3D model, SVG, or image into floating liquid glass with real refraction, dispersion, and frost.

将三维模型、SVG 或图片变为悬浮的液态玻璃，呈现折射、色散和磨砂效果。

[LeiBox demo and documentation](https://leibox.pantoria.cn/docs/components/glass-object) · [Canvas UI source](https://canvasui.dev/docs/components/glass-object)

Use the Canvas UI documentation to choose a framework and install from its original registry.

从 Canvas UI 原站选择框架和渲染器，按原站说明安装。
