# LeiBox · ei 连字矢量成稿与标准制图

用户最终选择原来的圆润 ei 连字，而不是后续的方箱变体。左侧图形直接引用项目 `public/leibox-mark.svg` 的正式路径，字标依据本目录 `selected-reference.png` 做几何规整。

## 原始构思与品牌记录

ei 连字的“人物与托举容器”构思来自用户当时的说明：i 的点和竖干像人的头与身体，e、i 的共享连接笔画像伸出的双手，e 的半圆像被捧着的容器，可联想到箱子。后续虽探索过方箱版本，最终采用的仍是这里的圆润 ei 连字。

用户已确定的品牌主张为“好界面，从一次忍不住的点击开始。”原始对话出处、形态对应关系和品牌确认范围统一记录在项目根目录的 [BRAND.md](../../../BRAND.md)。Logo 释义沿用原始讨论，不将它反推为当初专为这句主张设计。

第一张为 B 式比例定位表达：图形、图文间距、字标宽度、字高线、基线、原图标的实际构造圆与 ei 连字的共享笔画。第二张补充字标中的真实圆、椭圆、端圆及 B 字腔的三次 Bézier 参数。排线仅用于制图，成品保持纯色透明。

本次定义 x = 主笔画 16u。组合图形高为 13x，图文净距为 2.75x，字标高为 6.25x，字标宽为 23x，组合宽约为 37.744x。ei 连笔及 i 竖干使用 0.875x 作为光学校正；不是所有笔画被强制做成同宽。标注显示到三位小数，原始精度保留在参数文件中。

## 保留与调整

- 保留 LeiBox 拼写、圆润 L、e-i 斜向连笔、独立圆点、e 下方开口、B 双字腔及 o 内白。
- 规整位图边缘与圆角，校正连笔粗细、i 的位置和 x 的字宽。e 的圆弧端部与连笔下沿按相切约束定位，避免并集边界出现多余凸起。
- B 使用独立三次曲线保留字腔比例；o 使用椭圆，未将它们虚构为正圆。
- ei 中字母笔画的交汇处保留字形需要的转角；解析相切检查针对实际圆弧、端圆和直线的平滑接缝，不声称整个字标处处光滑。

## 已运行的验证

`validation.json` 记录原 SVG 路径及 SHA-256 一致、成品不含字体/位图、透明与反白 alpha 一致、实际导出的圆弧接缝，以及 16 / 24 / 25 / 32 / 48px 栅格检查。32px 和 48px 下，三个 alpha 阈值都保持预期的 7 个实体与 5 个孔洞；24/25px 对阈值较敏感，16px 已有粘连。32px 是本次栅格测试的建议，不能因此放大网站已有的 Logo；网站按用户更正保留原来的 25px 显示高度并等比缩放。

[最终字标原图对照](review-accepted/comparison.png)、[差异叠加](review-accepted/difference.png)和 [数值记录](review-accepted/review.json)使用整体等比缩放和中心配准，没有局部拉伸。原图字标仅 92×25 像素；重建后的字标保留原来的 6 个实体与 4 个孔洞。面积交并比与轮廓距离属于像素对照，不等于品牌识别准确率。

最终字标像素交并比为 84.86%；平均轮廓偏差约 0.28 个原图像素，P95 约 0.91 像素、最大约 1.72 像素。原图阈值为 128，边界没有降采样。成品和两张制图从参数重新生成后，5 个关键 SVG 的 SHA-256 完全一致，记录在 `rebuild-check.json`。

这是对用户选定图的几何规整；精确半径、模数和字距为本次拟合及定义，没有推断原字体名称。已查看实际成品、反白、原图叠加、ei 局部和两张制图。未做外部人员识别测试或印刷打样。

## 参数复建

在项目根目录运行：

```powershell
node design/brand/leibox-ei-20261023/build.mjs
python design/brand/leibox-ei-20261023/validate.py
```

`parameters.json` 是编辑入口，`geometry.json` 包含计算后的精确坐标、轮廓与构造依据。制作前结构基线在 `source-baseline.json`；中间稿与检查记录独立保存。

用户确认后，这版组合已用于 [LeiBox 正式网站](https://leibox-ui.netlify.app) 的共用 Logo 和网页分享图。页面通过等比 SVG 显示，明暗主题分别使用黑色与反白效果；原图形、favicon 与应用图标保持原样。初次发布版本为 `6adb27b845dd22480c98c31d`，发布回执与核验记录位于 `work/logo-rollout-20261023/`。随后按用户更正，网站 Logo 恢复原有 25px 显示高度，矢量母版本身未改；修正版本 `6adb3203352195a391a0fb16` 的记录位于 `work/logo-size-fix-20261023/`。
